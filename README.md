# Time Series Data Pipeline

## Project Overview
This group project focuses on time-series data analysis and forecasting. It combines data preprocessing, exploratory data analysis, machine learning, database design, API development, and prediction integration.

## Project Objectives
- Explore and preprocess a time-series dataset from Kaggle.
- Perform exploratory data analysis and answer analytical questions using visualizations.
- Train and evaluate forecasting models.
- Design and implement a relational database using MySQL and a NoSQL database using MongoDB.
- Develop CRUD API endpoints and time-series queries.
- Build a script that fetches data from the API and generates predictions.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn or TensorFlow
- MySQL
- MongoDB
- FastAPI

## Project Structure
The repository will be organized into folders for data analysis, machine learning, databases, API development, prediction scripts, and documentation.
